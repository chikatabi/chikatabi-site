2026年10月時点の情報です。

ANAのアップグレードポイントがなくなると発表されてから、「2027年からはダイヤモンドを取っても意味がない」と受け取る声があります。

**結論を先に書くと、2027年4月に終わるのはアップグレードポイントで、ダイヤモンドそのものではありません。** 2027年4月1日の時点でダイヤモンドの人には、50,000マイルが入ります。座席のアップグレードもラウンジも、これからはマイルで使う形になります。ダイヤモンドになる条件も変わっていません。

## 2027年4月に変わること

ANAのお知らせに書かれている内容を並べると、次のとおりです。

| 項目 | 内容 |
|---|---|
| アップグレードポイント | 2026年度の提供で終了 |
| アップグレードポイントでの座席アップグレード（ダイヤモンド限定） | 2027年3月31日で終了 |
| 2026年度にもらったアップグレードポイントの期限 | 2027年3月31日の搭乗・利用分まで |
| 代わりに入るもの | 50,000マイル |
| もらえる人 | 2027年4月1日の時点でダイヤモンドの人 |
| 入る時期 | 2027年4月ごろの予定 |
| 入る口座 | グループ4（航空関連のサービスに使える期間限定のマイル） |

2026年度のアップグレードポイントが手元に残っている人は、2027年3月31日の搭乗・利用分までに使い切る必要があります。

50,000マイルには注意点が1つあります。グループ4のマイルは期間限定で、ANAのページには「キャンペーンにより有効期限が異なります」と書かれています。この50,000マイルの有効期限は、2026年10月の時点ではまだ発表されていません。

## ダイヤモンドになる条件は変わらない

ダイヤモンドの条件は、1年間のプレミアムポイントが100,000、そのうちANAグループ運航便で50,000です。アップグレードポイントの終了とあわせて条件が変わった、という発表はありません。

今年100,000に届きそうかどうかは、ANAのウェブサイトの「ご利用実績照会」で見られます。届きそうな人は、2027年4月ごろに50,000マイルが入ること、それが期間限定のマイルであることを、来年の予定に入れておくと使い忘れを防げます。

## 50,000マイルで使えるもの・使えないもの

グループ4のマイルで使えるのは、航空関連のものに限られます。

| 使えるもの | 使えないもの |
|---|---|
| 国内線・国際線の特典航空券 | ホテルやレンタカーなどの旅行のサービス |
| 提携航空会社の特典航空券 | ANA Payへのチャージ |
| 国内線・国際線のアップグレード | ANA Mallなどの日常の買い物 |
| ANA SKY コインへの交換 | |

ふつうのマイルのように何にでも使えるわけではありませんが、アップグレードポイントで多くの人がしていた「座席を上げる」使い方は、このマイルで続けられます。

## 国内線もマイルでアップグレードできる

ANAのお知らせでは、座席のアップグレードとラウンジは、アップグレードポイントが終わったあともマイルで使えるとされています。

国際線は、もともとマイルでアップグレードができました。国内線も、2026年5月19日の搭乗分からマイルでアップグレードできるようになっています。

対象になるのは、フレックス、スタンダード、株主優待割引などの運賃です。シンプルは対象に入っていません。必要なマイルは1区間4,000マイルからで、東京発着の例は次のとおりです。

| 区間（東京発着） | 片道に要るマイル |
|---|---|
| 大阪 | 11,000マイル |
| 札幌 | 15,000マイル |
| 沖縄 | 18,000マイル |

往復でアップグレードすると、東京と沖縄なら18,000マイルの2区間で36,000マイル、東京と大阪なら22,000マイルです。50,000マイルは、こうしたアップグレードに何回か使える量です。

ダイヤモンドなどのプレミアムメンバーが自分のマイルで本人が乗る場合は、アップグレードの予約と空席待ちを優先して受け付けてもらえます。

## ラウンジはマイルで使う形に

ANAのラウンジには、今もマイルで利用できるサービスがあり、ANAのページにはラウンジごとに必要なマイル数の表が載っています。

これまでアップグレードポイントでしか使えなかった一部のラウンジのサービスも、今後はマイルで使えるようになるとされています。ただ、いつから始まるのか、何マイル要るのかは、2026年10月の時点では決まっていません。

## この先の特典はどうなるか（予想）

ここからは、ANAが発表していない内容についての、CHIKATABIの予想です。公式の情報ではありません。

予想の材料は3つです。

1. ANAのお知らせでは、アップグレードもラウンジもマイルで使う形になっている。報道でも、特典をマイルに一本化すると伝えられている
2. 2026年度の選択式特典には、まだ「アップグレードコース」（アップグレードポイント12ポイント）が残っている。選択式特典の中身が本当に変わるのは2027年度から
3. JALは2028年度から、上級会員に毎年のボーナスマイルを新しく設けると報じられている（ダイヤモンドメタル30,000マイル、JMBダイヤモンド20,000マイル、JMBプレミア10,000マイル）

ここから考えられることは2つあります。1つは、2027年度の選択式特典でアップグレードコースがなくなり、マイルで受け取るコースが入るのではないか、ということです。もう1つは、50,000マイルが1回きりなのか毎年なのか、という点です。ANAのお知らせは「これまでのご愛顧への感謝の気持ちといたしまして」と書いていて、2027年度の分しか触れていません。JALが毎年のボーナスマイルを選んだことから、ANAも毎年のマイルを考える可能性はあると見ています。

もう1つ、2027年度のダイヤモンドの使い心地を大きく左右するのが、ラウンジのサービスが何マイルになるかです。

2026年度の選択式特典は、2025年12月から2026年2月にかけて、達成の時期に応じて申し込みが始まりました。2027年度の案内が同じころに出たら、アップグレードコースの代わりに何が入ったかを最初に見てください。
